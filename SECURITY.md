# Security policy

Report suspected vulnerabilities privately, never in a public issue. Use
[private vulnerability reporting](https://github.com/gethandup/handup/security/advisories/new)
on this repository.

Include the affected version, steps to reproduce, impact and how to reach you.
Security fixes ship in the latest release only.

The relay's security properties are described in
[docs/public/relay.md](docs/public/relay.md).
